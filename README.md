# 🌍 Atlas Path — A Modern Travel Memory App

City Journal is a sleek, modern, and interactive travel journaling app that allows users to log, explore, and reflect on the cities they have visited around the world. Built with a clean UI, smooth interactions, and real-world APIs, it brings together mapping, journaling, exploration, and insights into one seamless experience.

---

## ✨ Features

### 📍 **Interactive Map (Leaflet + LocationIQ)**

- Click anywhere on the interactive map to select a city.
- The app fetches city details using **LocationIQ** (name, country, coordinates, etc.).
- Automatically retrieves the **country flag** and a related **city image**.
- Displays a dynamic page showing the location and metadata.

---

### 📝 **City Journaling**

- Save cities you have visited along with:

  - Date visited (via a clean calendar UI).
  - A personal note.
  - Auto-fetched city image and country flag and metadata.

- Edit notes at any time.
- Delete entries instantly.
- All saved cities appear on the home page with:

  - Image thumbnail
  - Note excerpt
  - Country or city name.
  - Country flag.
  - Date visited

---

### 🌐 **Explore Section**

- Browse an image gallery of world cities.
- Lightbox integration for immersive fullscreen viewing.
- Sub-pages:

  - **Gallery** — curated or dynamic city photos.
  - **Blog** — powered by **Sanity CMS** with a custom schema for easy writing.

---

### 📊 **Stats Page**

- View insights on your travel history.
- Count how many cities and countries you’ve visited.
- Visual breakdown of your travel footprint.

---

### 💬 **Chatbot Integration (Cerebras)**

- Ask city‑related questions directly inside the app.
- Perfect for travel tips, fast lookup, curiosity, and exploration.
- Chatbot designed to respond with context around cities, countries, history, and culture.

---

## 🏠 Additional Pages

- **Countries Page** — Shows all countries associated with your saved cities.
- **Cities Page** — Clean overview of all saved cities.
- All pages are fully responsive with a modern, minimal aesthetic.

---

## 🔧 Tech Stack

- **Next.js**
- **Leaflet.js** — Interactive mapping
- **LocationIQ API** — City data & geocoding
- **Sanity CMS** — Blog management
- **Tailwind CSS** — Styling
- **Lightbox / Photo viewer** — Gallery experience
- **Cerebras API** — Chatbot functionality
- **Tanstack Query** — Data fetching
- **Shadcn UI** — UI components

---

## 🚀 Purpose of the App

City Journal is built for modern travelers—especially during festive seasons like Christmas, when many people travel abroad and want an easy way to remember the places they visit.

It is a personal memory companion:

- Save places you've been.
- Add context and emotions through notes.
- Explore visuals.
- Read location‑themed blogs.
- Chat with an AI assistant.
- Keep all your travel footprints in one place.
